# ساخت فایل نصبی و به‌روزرسانی خودکار

دو ربات برای این کار هست: یکی فایل نصبی می‌سازد، یکی نسخهٔ نصب‌شده روی
دسکتاپ را به‌روز می‌کند.

---

## ۱) ربات ساخت فایل نصبی

### پیش‌نیازها

* پایتون ۳٫۱۱ یا بالاتر (هنگام نصب حتماً «Add Python to PATH» را بزنید)
* [Inno Setup 6](https://jrsoftware.org/isdl.php) — رایگان

### اجرا

```bat
scripts\build_installer.bat
```

همین. ربات این کارها را پشت سر هم انجام می‌دهد:

| گام | کار |
|-----|------|
| ۱ | خواندن نسخه از `app/core/constants.py` |
| ۲ | نصب وابستگی‌ها |
| ۳ | اجرای کل آزمون‌ها — **با شکست آزمون، ساخت متوقف می‌شود** |
| ۴ | ساخت فایل اجرایی با PyInstaller |
| ۵ | ساخت فایل نصبی با Inno Setup |
| ۶ | نوشتن `latest.json` برای ربات به‌روزرسانی |

### خروجی

```
dist\CryptoAITrader\CryptoAITrader.exe          ← نسخهٔ قابل حمل
dist\installer\CryptoAITrader-Setup-<نسخه>.exe  ← فایل نصبی
dist\installer\latest.json                      ← برای به‌روزرسانی
```

فایل نصبی میان‌بر منوی استارت و (به انتخاب کاربر) دسکتاپ می‌سازد،
برنامه را در «افزودن/حذف برنامه‌ها» ثبت می‌کند و حذف‌کننده دارد.

> اگر Inno Setup نصب نباشد، گام ۵ رد می‌شود و پیام می‌دهد؛ فایل اجرایی
> در `dist\CryptoAITrader` همچنان کاملاً قابل استفاده است.

---

## ۲) ربات به‌روزرسانی

### راه‌اندازی

۱. پوشهٔ `dist\installer` (شامل فایل نصبی و `latest.json`) را جایی
   بگذارید که دستگاه مقصد ببیند: یک پوشهٔ شبکه، فلش، یا یک آدرس وب.
۲. در برنامه: **تنظیمات ← پشتیبان‌گیری ← به‌روزرسانی برنامه**
۳. «منبع به‌روزرسانی» را همان مسیر یا نشانی بگذارید.
۴. «بررسی به‌روزرسانی» را بزنید.

نمونه‌ها:

```
D:\shared\CryptoAITrader
\\server\releases\CryptoAITrader
https://example.com/cryptoaitrader
```

### چه اتفاقی می‌افتد

۱. `latest.json` خوانده می‌شود.
۲. نسخه‌اش **عددی** با نسخهٔ فعلی مقایسه می‌شود.
۳. اگر جدیدتر بود، فایل نصبی دانلود و با SHA-256 بررسی می‌شود.
۴. نصب‌کننده اجرا می‌شود و نسخهٔ قبلی را جایگزین می‌کند.

### دو تضمین مهم

**دادهٔ شما دست نمی‌خورد.** پایگاه داده، تنظیمات، حساب‌های صرافی و
سابقهٔ سیگنال‌ها بیرون از پوشهٔ برنامه‌اند و نه به‌روزرسانی و نه حتی
حذف برنامه به آن‌ها کاری ندارد.

**فایل خراب اجرا نمی‌شود.** اگر SHA-256 نخواند، فایل پاک می‌شود و
پیام خطا می‌آید. اجرای یک نصب‌کنندهٔ ناقص بدتر از به‌روز نشدن است.

### چرا مقایسهٔ نسخه عددی است

در مقایسهٔ رشته‌ای `"1.9.9" > "1.9.11"` می‌شود (چون «۹» از «۱»
بزرگ‌تر است). با این اشتباه، هر کاربری که روی نسخهٔ دورقمی باشد دیگر
هیچ به‌روزرسانی‌ای نمی‌گرفت و هیچ‌کس هم متوجه نمی‌شد. آزمون
`test_two_digit_patch_beats_single_digit` این را قفل کرده است.

## عیب‌یابی

| نشانه | علت | چاره |
|-------|------|------|
| «Inno Setup نصب نیست» | ISCC روی PATH نیست | Inno Setup 6 را نصب کنید |
| ساخت در گام آزمون می‌ایستد | آزمونی شکسته | آزمون را درست کنید؛ `SKIP_TESTS=1` فقط برای اضطرار |
| آنتی‌ویروس هشدار می‌دهد | فایل PyInstaller بدون امضای دیجیتال | عادی است؛ برای انتشار عمومی گواهی امضا بگیرید |
| «منبع را وارد کنید» | مسیر خالی است | مسیر پوشه یا نشانی را بگذارید |
| نسخهٔ تازه دیده نمی‌شود | `latest.json` نیست یا نسخه‌اش قدیمی‌تر است | فایل را کنار نصب‌کننده بگذارید |
