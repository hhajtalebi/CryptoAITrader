# ساخت نسخهٔ ویندوزی با PyInstaller

این راهنما می‌گوید چطور از کد، یک پوشهٔ اجرایی ویندوزی بسازید.

## پیش‌نیاز

```bat
python -m pip install -r requirements.txt
python -m pip install pyinstaller
```

پایتون ۳٫۱۱ یا بالاتر، ۶۴ بیتی.

## ساخت

```bat
pyinstaller CryptoAITrader.spec --noconfirm
```

خروجی در `dist\CryptoAITrader\` ساخته می‌شود و فایل اجرایی
`dist\CryptoAITrader\CryptoAITrader.exe` است. کل همین پوشه را باید به
کاربر داد؛ فقط فایل exe به‌تنهایی کار نمی‌کند.

## چه چیزهایی داخل بسته می‌روند

`PyInstaller` فقط ماژول‌های پایتون را دنبال می‌کند. هر چیزی که در زمان
اجرا از روی مسیر فایل خوانده می‌شود باید صریح در `datas` بیاید:

| داده | چرا لازم است |
|---|---|
| `localization/fa`, `localization/en` | بدون این، همهٔ متن‌ها به کلید خام تبدیل می‌شوند |
| `ai/prompts` | قالب‌های پرامپت مدل |
| `assets/fonts` | **قلم فارسی خروجی PDF** — بدون این، گزارش فارسی به‌هم‌ریخته چاپ می‌شود |
| `migrations` + `alembic.ini` | ساخت و ارتقای پایگاه داده در نخستین اجرا |
| `docs`, `README*.md` | راهنمای داخل برنامه |

ماژول‌هایی که با نام و در زمان اجرا بارگذاری می‌شوند (رجیستری صرافی،
اندیکاتور، استراتژی، ارائه‌دهندهٔ هوش مصنوعی) در تحلیل ایستا دیده
نمی‌شوند و در `hiddenimports` فهرست شده‌اند. اگر صرافی یا اندیکاتور
تازه‌ای افزودید و در نسخهٔ بسته‌بندی‌شده «پیدا نشد» گرفتید، ریشه معمولاً
همین‌جاست.

## کوچک‌کردن خروجی

`excludes` در فایل spec حدود ۲۸۰ مگابایت کم می‌کند. این‌ها وابستگی‌های
*اختیاری* `pandas`/`pyqtgraph` هستند که برنامه هیچ‌جا وارد نمی‌کند
(`numba`، `llvmlite`، `scipy`، `lxml`، `PIL`، `matplotlib`).

> **هشدار:** زیرماژول‌های خود `pandas` را به `excludes` اضافه نکنید.
> `pandas.api.typing` آن‌ها را بی‌قیدوشرط وارد می‌کند و برنامه هنگام بالا
> آمدن با `ModuleNotFoundError: pandas.io.stata` می‌شکند. این مورد آزموده
> شده است.

اندازهٔ خروجی سالم: حدود ۳۳۰ مگابایت.

## آزمون بستهٔ ساخته‌شده

پیش از تحویل، دست‌کم این دو را اجرا کنید:

```bat
dist\CryptoAITrader\CryptoAITrader.exe --check
dist\CryptoAITrader\CryptoAITrader.exe --signal BTC/USDT
```

اولی باید `Health check passed.` بدهد و دومی باید یک سیگنال کامل چاپ
کند. سپس برنامه را عادی باز کنید و یک بار خروجی PDF فارسی بگیرید تا از
سالم‌بودن قلم مطمئن شوید.

## نکته‌های رایج

- **پنجرهٔ کنسول باز می‌شود؟** `console=False` در spec باید باقی بماند.
- **آنتی‌ویروس هشدار می‌دهد؟** برای فایل‌های PyInstaller بدون امضای
  دیجیتال عادی است؛ راه‌حل درست، امضای کد است.
- **اجرای اول کند است؟** بار اول پایگاه داده ساخته و مهاجرت‌ها اجرا
  می‌شوند.
- **داده‌های کاربر کجاست؟** کنار فایل اجرایی نیست؛ در پوشهٔ دادهٔ کاربر
  ویندوز است، پس به‌روزرسانی برنامه تنظیمات را پاک نمی‌کند.
