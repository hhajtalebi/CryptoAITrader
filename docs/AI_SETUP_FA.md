# راهنمای فعال‌سازی هوش مصنوعی

این راهنما توضیح می‌دهد چگونه هوش مصنوعی برنامه را فعال کنید، چگونه از
**مدل‌های رایگان** استفاده کنید، و اگر Ollama روی سیستم شما اجراست ولی
برنامه به آن وصل نمی‌شود چه کار کنید.

---

## ۱. خلاصه سریع

هوش مصنوعی از نسخه ۱.۳ **به‌صورت پیش‌فرض فعال** است. کافی است یکی از این
سه مسیر را انتخاب کنید:

| مسیر | هزینه | نیاز به کلید | نیاز به فیلترشکن |
|---|---|---|---|
| **Ollama روی سیستم خودتان** | رایگان | ندارد | ندارد |
| **Groq / Google Gemini / OpenRouter** | سطح رایگان دارد | دارد (رایگان) | معمولاً دارد |
| **OpenAI / Anthropic و…** | پولی | دارد | دارد |

پیشنهاد ما: با **Ollama** شروع کنید. کاملاً رایگان است، داده‌هایتان از
سیستم خارج نمی‌شود، و به هیچ کلیدی نیاز ندارد.

---

## ۲. Ollama — مسیر رایگان و محلی

### نصب و راه‌اندازی

۱. از [ollama.com/download](https://ollama.com/download) نسخه ویندوز را نصب کنید.
۲. یک مدل بگیرید. در Command Prompt بنویسید:

```
ollama pull qwen2.5
```

مدل‌های پیشنهادی بر اساس توان سیستم:

| رم سیستم | مدل پیشنهادی | دستور |
|---|---|---|
| ۸ گیگابایت | `qwen2.5:3b` | `ollama pull qwen2.5:3b` |
| ۱۶ گیگابایت | `qwen2.5` (۷B) | `ollama pull qwen2.5` |
| ۳۲ گیگابایت به بالا | `qwen2.5:14b` | `ollama pull qwen2.5:14b` |

۳. مطمئن شوید سرویس بالا است:

```
ollama list
```

### تنظیم در برنامه

به **تنظیمات ← هوش مصنوعی** بروید:

- **فعال‌سازی هوش مصنوعی**: تیک بخورد
- **سرویس**: `Ollama (محلی)`
- **نشانی**: `http://127.0.0.1:11434`
- دکمه **دریافت مدل‌ها** را بزنید تا فهرست مدل‌های نصب‌شده بیاید
- مدل را انتخاب و **ذخیره** کنید
- دکمه **آزمایش اتصال** باید پیام سبز بدهد

### «Ollama اجراست ولی برنامه وصل نمی‌شود»

این ایراد در نسخه‌های قبلی وجود داشت و اکنون برطرف شده است. سه علت داشت:

**۱) نام مدل با آنچه نصب کرده‌اید فرق داشت.**
پیش‌فرض برنامه `llama3.1` بود. اگر شما `qwen2.5` نصب کرده بودید، برنامه
شکست می‌خورد. حالا اگر مدل تنظیم‌شده نصب نباشد، برنامه **خودکار** یکی از
مدل‌های نصب‌شده را انتخاب می‌کند.

**۲) `localhost` روی برخی ویندوزها به IPv6 (`::1`) ترجمه می‌شود** در حالی
که Ollama فقط روی `127.0.0.1` گوش می‌دهد. حالا برنامه هر دو نشانی را
امتحان می‌کند. اگر باز هم مشکل داشتید، نشانی را دستی روی
`http://127.0.0.1:11434` بگذارید.

**۳) مهلت زمانی کوتاه بود.** اولین پاسخ یک مدل محلی شامل بارگذاری مدل در
حافظه است و می‌تواند ۳۰ تا ۹۰ ثانیه طول بکشد. مهلت خواندن حالا دست‌کم
۱۲۰ ثانیه است.

اگر همچنان وصل نشد:

```
curl http://127.0.0.1:11434/api/tags
```

اگر این دستور جواب نداد، مشکل از خود Ollama است نه برنامه. سرویس را با
`ollama serve` اجرا کنید و فایروال ویندوز را بررسی کنید.

## ۳. مدل‌های رایگان ابری

در **تنظیمات ← هوش مصنوعی** گزینه‌ای هست به نام **«فقط مدل‌های رایگان»**
که به‌صورت پیش‌فرض روشن است. با روشن بودن آن، فقط مدل‌هایی در فهرست
نمایش داده می‌شوند که هزینه‌ای ندارند.

فهرست مدل‌ها همیشه **از خود سرویس** گرفته می‌شود (دکمه «دریافت مدل‌ها»)
و به این ترتیب مرتب می‌شود:

```
رایگان  →  کم‌هزینه  →  نامشخص  →  پولی
```

### سرویس‌های دارای سطح رایگان

| سرویس | چطور کلید بگیرید | نکته |
|---|---|---|
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | بسیار سریع، سطح رایگان سخاوتمندانه |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | سطح رایگان خوب، مناسب تحلیل چندتایم‌فریمی |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | ده‌ها مدل با یک کلید؛ مدل‌های `:free` رایگان‌اند |

در OpenRouter، هر مدلی که نامش به `:free` ختم شود کاملاً رایگان است.

## ۴. OpenAI

### وضعیت کلید شما

کلیدی که ارائه کردید **معتبر است** — فهرست ۱۱۹ مدل را برمی‌گرداند. اما
حساب آن **اعتبار مالی ندارد**:

```
insufficient_quota — You have no credits remaining.
                     Add credits to continue using the API.
```

این یعنی هر درخواست تحلیل یا چت با خطا برمی‌گردد. کلید در برنامه ذخیره و
رمزنگاری شده و **به‌محض شارژ حساب، بدون هیچ تنظیم اضافه‌ای کار خواهد کرد**.

برنامه حالا این وضعیت را با پیام روشن گزارش می‌دهد («اعتبار حساب تمام
شده») به‌جای یک کد HTTP مبهم.

### شارژ اعتبار

اعتبار API از اشتراک ChatGPT Plus **جداست**. شارژ آن از
[platform.openai.com/settings/organization/billing](https://platform.openai.com/settings/organization/billing)
انجام می‌شود و به کارت اعتباری بین‌المللی نیاز دارد.

### درباره «لایسنس مارکت» و سایت‌های مشابه

بررسی کردم. نکاتی که باید بدانید:

- این سایت‌ها عمدتاً **اکانت ChatGPT Plus** می‌فروشند، نه **اعتبار API**.
  این دو کاملاً متفاوت‌اند: اشتراک Plus فقط برای استفاده از سایت
  chatgpt.com است و **هیچ اعتبار API‌ای به شما نمی‌دهد**. برنامه ما فقط با
  API کار می‌کند، پس اکانت Plus به درد این برنامه **نمی‌خورد**.
- «لایسنس مارکت» اکانت **OpenRouter** هم می‌فروشد. آن یکی چون سازگار با
  API است، با این برنامه کار می‌کند — ولی خودتان می‌توانید رایگان در
  openrouter.ai ثبت‌نام کنید و از مدل‌های `:free` استفاده کنید.
- اگر می‌خواهید حتماً از مدل‌های OpenAI استفاده کنید و کارت بین‌المللی
  ندارید، واسط‌های ایرانی سازگار با API گزینه معقول‌تری هستند:
  **AvalAI** (`api.avalai.ir`) و **Liara AI** (`ai.liara.ir`). هر دو در
  فهرست سرویس‌های برنامه هستند و با ریال شارژ می‌شوند.

⚠️ توصیه امنیتی: کلید API‌ای که از واسطه می‌خرید، در اختیار آن واسطه هم
هست. برای این برنامه که فقط تحلیل بازار می‌کند ریسک بالایی ندارد، ولی
هرگز چنین کلیدی را جای حساس دیگری استفاده نکنید.

## ۵. بخش چت با هوش مصنوعی

در نوار کناری، بخش **«چت هوشمند»** اضافه شده است.

### چه کاری می‌کند

برخلاف یک چت‌بات معمولی، این دستیار **به داده‌های زنده صرافی شما دسترسی
دارد**. وقتی می‌پرسید «قیمت بیت‌کوین چنده؟»، واقعاً قیمت را از صرافی
می‌گیرد و بعد جواب می‌دهد — عدد از خودش درنمی‌آورد.

ابزارهایی که در اختیار دارد: قیمت لحظه‌ای، آمار ۲۴ ساعته، کندل‌ها،
۲۴ اندیکاتور، عمق بازار، تشخیص روند، ساختار بازار، سطوح حمایت و مقاومت،
و محاسبه ریسک.

زیر هر پاسخ، فهرست ابزارهایی که استفاده کرده نمایش داده می‌شود تا بدانید
عدد از کجا آمده است.

### اقدام‌ها

دستیار می‌تواند کاری را **پیشنهاد** کند — مثلاً «برایت سیگنال بگیرم؟».
در این حالت دکمه‌ای سبز زیر گفتگو ظاهر می‌شود.

🔒 **نکته امنیتی مهم**: هیچ اقدامی خودکار اجرا نمی‌شود. تا شما روی دکمه
کلیک نکنید، هیچ اتفاقی نمی‌افتد. این طراحی عمدی است: یعنی حتی اگر متنی
مخرب از داده‌های بازار وارد گفتگو شود، نمی‌تواند معامله‌ای باز کند.

اقدام‌های مجاز فقط این چهار موردند: تولید سیگنال، اجرای تحلیل، باز کردن
معامله کاغذی، و رفتن به صفحه بازارها. هر پیشنهاد دیگری نادیده گرفته
می‌شود.

### نکات کاربردی

- نماد و تایم‌فریم را از بالای صفحه انتخاب کنید تا وقتی می‌گویید
  «تحلیلش کن»، دستیار بداند منظورتان چیست.
- به فارسی بنویسید، فارسی جواب می‌دهد.
- دکمه **«گفتگوی جدید»** حافظه دستیار را پاک می‌کند. اگر موضوع را کاملاً
  عوض می‌کنید، این کار پاسخ‌ها را دقیق‌تر می‌کند.
- گفتگو حافظه دارد ولی برای صرفه‌جویی در توکن، فقط ۲۴ پیام آخر نگه داشته
  می‌شود.

## ۶. رفع اشکال

| نشانه | علت محتمل | راه‌حل |
|---|---|---|
| «هیچ سرویس هوش مصنوعی پیکربندی نشده» | سرویس انتخاب نشده | تنظیمات ← هوش مصنوعی ← سرویس را انتخاب و ذخیره کنید |
| «اعتبار حساب تمام شده» | کلید معتبر ولی بدون شارژ | حساب را شارژ کنید یا سرویس رایگان انتخاب کنید |
| «احراز هویت ناموفق» | کلید غلط یا منقضی | کلید تازه بگیرید و دوباره ذخیره کنید |
| «مدل در دسترس نیست» | نام مدل اشتباه | دکمه «دریافت مدل‌ها» را بزنید و از فهرست انتخاب کنید |
| Ollama وصل نمی‌شود | نشانی یا مدل | بخش ۲ همین سند |
| پاسخ‌ها بی‌کیفیت‌اند | مدل خیلی کوچک | مدل بزرگ‌تر بگیرید (`qwen2.5:14b`) یا سرویس ابری |
| تحلیل خیلی طول می‌کشد | مدل محلی روی CPU | مدل کوچک‌تر، یا `ai.agent_timeout` را بالا ببرید |

### کلیدها کجا ذخیره می‌شوند؟

کلید هر سرویس جداگانه و **رمزنگاری‌شده** ذخیره می‌شود
(`ai.<provider>.api_key`). با تعویض سرویس، کلید همان سرویس خودکار
بارگذاری می‌شود. کلید هرگز در لاگ‌ها نوشته نمی‌شود و در پایگاه داده به
صورت متن خام وجود ندارد.

## ۷. ترتیب پیش‌فرض تلاش (Fallback)

اگر گزینه «سرویس جایگزین» روشن باشد و سرویس اصلی پاسخ ندهد، برنامه
خودکار سراغ سرویس بعدی می‌رود. این یعنی می‌توانید Ollama را به‌عنوان
گزینه اصلی و یک سرویس ابری را به‌عنوان پشتیبان داشته باشید — یا برعکس.
