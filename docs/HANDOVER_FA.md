همه‌چیزِ لازم اینجاست: وضعیت فعلی، قواعد کار، و تله‌هایی که قبلاً وقت
زیادی گرفتند.

**۱۹۹۹ آزمون قبول / ۰ مردود**.

## ۳. قواعد کار (خواستهٔ صریح کاربر)

این‌ها سلیقه نیستند؛ کاربر مستقیماً گفته است:

- **هیچ‌وقت پروژه را خراب رها نکن.** هر بخش را تمام کن، بعد ZIP بساز.
- **هیچ‌وقت قابلیت موجود را حذف نکن.** پیش از تغییر، کد را بخوان.
- **هیچ‌وقت پایگاه داده یا تنظیمات کاربر را بازنشانی نکن.**
- **هیچ پیاده‌سازی قلابی (mock-only) نباشد.** داده باید واقعی باشد.
- **هیچ متن UI به‌صورت درج‌شده در کد نباشد** — همه از `localization/`.
- **توضیحات و docstring فارسی** باشند و «چرا» را بگویند نه «چه».
- **پوستهٔ پیش‌فرض همیشه `corporate_navy`** («سرمه‌ای اداری»).
- **پوسته نباید قابلیت را قفل کند** (Feature ≠ Theme).
- **`BTC/USDT` هرگز در RTL به‌هم نریزد.**
- **اعتبار عدد اطمینان جدی است:** اگر ۹۰٪ گفته شد، نباید ضرر بدهد.
- **معاملهٔ خودکار پیش‌فرض کاغذی** با کلید تبدیل به واقعی در تنظیمات؛
  همهٔ عددها (هدف سود، حد ضرر، اهرم) دست کاربر؛ صرافی هم انتخاب کاربر.
- **سازندهٔ برنامه: حسین حاج طالبی** (پایین صفحه).

## ۴. محیط توسعه — تله‌های واقعی

### ۴٫۱ جعبهٔ شنی بسته‌ها را گم می‌کند
در شروع هر جلسه:

```bash
cd /home/user/CryptoAITrader
pip install -q -r requirements.txt
pip install -q pyflakes
python3 -c "import pydantic_settings, PySide6, pyflakes; print('deps OK')"
```

اگر `libxkbcommon` گم شد:

```bash
cp /home/user/.locallibs/libxkbcommon.so.0.0.0 /home/user/.locallibs/libxkbcommon.so.0
```

### ۴٫۲ اجرای آزمون — دستور دقیق

```bash
cd /home/user/CryptoAITrader
export LD_LIBRARY_PATH=/home/user/.locallibs:$LD_LIBRARY_PATH
CAT_DATA_DIR=$(mktemp -d) QT_QPA_PLATFORM=offscreen \
  timeout 300 python3 -m pytest tests/FILE.py -p no:cacheprovider -o addopts=""
```

`-q` نزنید. برای کل مجموعه (~۲۰ دقیقه) حتماً `start_process`:

```bash
bash /home/user/run_suite_batched.sh > /tmp/suiteXXX.txt 2>&1
```

نتیجه را با `cat /tmp/suiteXXX.txt` بخوانید؛ `get_process_output` برای
این اسکریپت خروجی خالی می‌دهد. batch3 حدود ۱۲ دقیقه طول می‌کشد — عادی
است. اجرای با `nohup … &` **هرگز واقعاً اجرا نمی‌شود**.

### ۴٫۳ آزمایش زنده

```bash
CAT_DATA_DIR=$(mktemp -d) PYTHONPATH=. timeout 200 python3 -c "..." \
  2>&1 | grep -vE "INFO|WARNING|keyring"
```

`Application(AppPaths(Path(...)).ensure())` — حتماً `Path`، رشته خطا
می‌دهد.

## ۵. تله‌های کد (هر کدام یک بار وقت گرفتند)

- **`pyflakes` تمیز ≠ درست.** یک بار خطی وسط بلوک `if` افتاد و
  `pyflakes` قبول کرد ولی برنامه بالا نمی‌آمد. همیشه UI را واقعاً بسازید.
- **نام پارامترها را حدس نزنید.** `make_button(primary=True)` است نه
  `variant=`. `SYSTEM_PROMPT.format(...)` با کلید ساختگی `KeyError`.
- **نقش‌های معتبر پوسته فقط این‌ها هستند:** `chip_up`، `chip_down`،
  `chip_info`، `chip_warn`. `chip_success`/`chip_danger` وجود ندارند.
- **`set_role()` استفاده کنید نه `setProperty("role", …)`** — دومی سبک را
  دوباره محاسبه نمی‌کند.
- **`SignalRepository.get_with_analysis()` تاپل می‌دهد نه دیکشنری.**
  برای نمایش از `analysis_payload()` استفاده کنید.
- **`save_signal` فیلدهای تازه را بی‌صدا دور می‌ریزد** — ستون به ستون
  دستی ساخته می‌شود؛ افزودن فیلد به `TradingSignal` یعنی ویرایش آن هم.
- **`TradingSignal` اسلات‌محور است** و `to_dict()` شناسه ندارد؛
  `Application._last_signal_id` را بخوانید.
- **مهاجرت پایگاه داده:** نوشتن فایل Alembic کافی **نیست**. ستون تازه
  باید در `app/database/session.py::_add_missing_columns()` هم بیاید.
- **آزمونِ نصبِ تازه، خرابی ارتقا را پنهان می‌کند.** همیشه با پایگاه
  دادهٔ نسخهٔ قبل هم امتحان کنید.
- **افزودن ابزار AI یک قرارداد UI را می‌شکند:** باید در
  `ui/pages/chat_page.py::TOOL_NAME_KEYS` و `localization/*/chat.json`
  هم ثبت شود.
- **آزمونی که کل فایل را `grep` می‌کند، به توضیح فارسی هم گیر می‌دهد.**
  روی فراخوانی واقعی ادعا بزنید، نه حضور یک نام.
- **آزمون تازه را حتماً روی کد قدیمی اجرا کنید** تا ثابت شود واقعاً
  چیزی را می‌گیرد.
- **`getattr(obj, "x", None)` قرارداد شکسته را پنهان می‌کند** و
  `if value:` صفرِ معتبر را دور می‌ریزد.
- **هشدار‌های pyflakes موجود (مال ما نیست):** `OVERLAY_COLORS` و
  `exchange` در `main_controller.py`، `Sparkline` در `markets_page.py`،
  `Path` در `analysis_dialog.py`.

## ۶. ساخت بستهٔ خروجی

نسخه در **چهار جا**: `app/core/constants.py:13`، `pyproject.toml:7`،
`BUILD_INFO.txt` خط ۴ و ۶.

```bash
cd /home/user && zip -rq CryptoAITrader-vX.Y.Z-YYYY-MM-DD.zip CryptoAITrader \
  -x "*/__pycache__/*" "*.pyc" "*/.pytest_cache/*" "*/.ruff_cache/*" \
     "*/.mypy_cache/*" "*.db" "*.log" "*/data/*" "*/build/*" "*/dist/*" \
     "*/.git/*" "*/mock_*.py" "*/.venv/*" "*/node_modules/*" \
     "*/.buildozer/*" "*/bin/*" "*/doctor_report.txt"
```

`backup/` را **هرگز** حذف نکنید (بخشی از برنامه است).

بررسی نهایی: باز کردن در پوشهٔ تمیز ← نسخه در ۳ جا ← `grep` کلید محرمانه
(باید صفر باشد) ← آزمون‌ها ← `python3 main.py --check`.

خروجی سالم `--check`: نسخه، **۱۳۶ کلید تنظیمات**، ۲۴ اندیکاتور،
۵ راهبرد، LBank با ~۱۳۷۱ نماد، قیمت واقعی BTC.
