# اتصال به «آشنا هوش مصنوعی» (AshnaAI)

## راه‌اندازی در سه گام

۱. **کلید بگیرید** — [app.ashna.ai/account?tab=api](https://app.ashna.ai/account?tab=api)
   → «Create key». کلید فقط **یک بار** نمایش داده می‌شود؛ همان‌جا کپی کنید.

۲. **در برنامه:** تنظیمات ← هوش مصنوعی ← سرویس‌دهنده ←
   **«آشنا هوش مصنوعی (AshnaAI)»**

   نشانی خودکار پر می‌شود:

   ```
   https://api.ashna.ai/v1/api
   ```

۳. کلید را در کادر «کلید API» بچسبانید ← **ذخیره** ← «آزمایش اتصال».

سپس «دریافت فهرست مدل‌ها» را بزنید تا مدل‌های حسابتان مستقیم از خود
سرویس خوانده شوند.

> **نکتهٔ مسیر:** پایه `/v1/api` است، **نه** `/v1`. اگر دستی به `/v1`
> تغییرش دهید همهٔ درخواست‌ها خطای ۴۰۴ می‌گیرند با پیامی که ربطی به
> علت واقعی ندارد. یک آزمون این را قفل کرده تا کسی «اصلاحش» نکند.

---

## مدل‌های موجود

با یک کلید به همهٔ این خانواده‌ها دسترسی دارید:

| خانواده | نمونه شناسه‌ها |
|---------|----------------|
| آشنا | `ashna-x1` |
| OpenAI | `gpt-4o-mini`، `gpt-5.2`، `gpt-5.6-terra` |
| Anthropic | `claude-sonnet-5`، `claude-opus-5`، `claude-haiku-4.5` |
| Google | `gemini-3.1-Pro`، `gemini-2.5-Flash` |
| DeepSeek | `deepseek-v4-flash`، `deepseek-v4-pro` |
| GLM | `glm-5.3-flash`، `glm-5.3` |
| Kimi | `kimi-k3`، `kimi-k2-thinking` |
| xAI | `grok-4.3`، `grok-4-reasoning` |

شناسه‌ها **بدون پیشوند سازنده**اند: `gpt-4o-mini` درست است،
`openai/gpt-4o-mini` (سبک OpenRouter) غلط.

### پیشنهاد برای این برنامه

* **تحلیل سریع و ارزان:** `glm-5.3-flash` یا `deepseek-v4-flash`
* **تحلیل دقیق سیگنال:** `claude-sonnet-5` یا `gpt-5.2`
* **پویش انبوه:** اصلاً از هوش مصنوعی استفاده نکنید — موتور ریاضی این
  کار را می‌کند و توکن نمی‌سوزاند. بعد می‌توانید یک نتیجه را به هوش
  مصنوعی بفرستید.

## استفاده از ایجنت خودتان

اگر در آشنا ایجنت ساخته‌اید، به‌جای نام مدل **شناسهٔ ایجنت** را
بنویسید:

```
my-support-agent-8k2qv
```

آشنا همان دستورها، ابزارها و منابع دادهٔ ایجنت شما را سمت سرور اجرا
می‌کند. شناسه را از Agent Hub یا از نشانی مرورگر (`?agent=<id>`)
بردارید.

---

## امنیت

کلید شما مثل بقیهٔ کلیدها **رمزنگاری‌شده در پایگاه داده** ذخیره
می‌شود، در رابط کاربری ستاره‌دار نمایش داده می‌شود، و **هرگز در لاگ
نوشته نمی‌شود**.

## عیب‌یابی

| پیام | معنا | چاره |
|------|------|------|
| `401 invalid_api_key` | کلید غلط یا منقضی | کلید تازه بسازید |
| `404 model_not_found` | شناسهٔ مدل اشتباه | «دریافت فهرست مدل‌ها» را بزنید |
| `404` روی همهٔ درخواست‌ها | نشانی به `/v1` تغییر کرده | به `/v1/api` برگردانید |
| `403` | مدل در دسترس حساب شما نیست | مدل دیگری بزنید یا اشتراک را بررسی کنید |
| `429` | تعداد درخواست زیاد | چند لحظه صبر کنید |
