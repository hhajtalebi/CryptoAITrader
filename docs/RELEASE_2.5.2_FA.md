# گزارش تحویل نسخهٔ 2.5.2 — فیوچرز LBank: خطای HTTP 403

تاریخ: 2026-09-24 · شاخه: `arena/01a0cf53-cryptoaitrader` · مبنا: `982cce2` (2.5.0) + تغییرهای commit‌نشدهٔ 2.5.1
**این تغییرها طبق دستور صریح کاربر commit/push نشده‌اند.**

## گزارش کاربر پس از 2.5.1

```
✓ اسپات: ۳ دارایی دریافت شد.
✗ فیوچرز: دریافت نشد — NetworkError: HTTP 403 while calling /cfd/openApi/v1/prv/account
```

یعنی رفع اسپات 2.5.1 کار کرد و گزارش همگام‌سازی علت فیوچرز را نشان داد.

## علت

- دامنهٔ API قرارداد LBank (`lbkperp.lbank.com`، تنها دامنهٔ مستند) پشت **Cloudflare** است (IPهای `104.18.x`/`172.64.x`)؛
  دامنهٔ اسپات (`api.lbkex.com`) نیست. به همین دلیل اسپات کار می‌کند و فیوچرز نه.
- 403 بدون بدنهٔ JSON صرافی یعنی درخواست **پیش از رسیدن به API و پیش از بررسی کلید** رد شده است. امضا، بدنهٔ JSON و
  سرآیندهای `timestamp/signature_method/echostr` با مستند رسمی مطابقت دارند.
- محتمل‌ترین علت‌ها: «بررسی امضای مرورگر» Cloudflare که عامل کاربر ناآشنای برنامه (`CryptoAITrader/1.5`) را رد می‌کند
  (کد 1010)، یا مسدودی کشور/منطقه یا IP (کدهای 1009، 1006–1008، 1020). متن قبلی خطا بدنهٔ پاسخ را دور می‌ریخت و
  کد واقعی معلوم نبود.

## رفع

| # | تغییر | جزئیات |
|---|---|---|
| ۱ | سرآیندهای معمول مرورگر | کلاینت قرارداد `User-Agent` مرورگر Chrome، `Accept` و `Accept-Language` می‌فرستد (`BROWSER_HEADERS`). اگر علت کد 1010 بوده باشد، همین رفعش می‌کند. |
| ۲ | تشخیص دقیق 401/403 | اگر بدنه JSON صرافی باشد، کد خطای LBank مبناست (مثلاً کلید نامعتبر). صفحهٔ Cloudflare ← `AccessBlockedError` با کد، معنی و Ray ID: «HTTP 403 blocked by Cloudflare 1020 — access denied by firewall rule». کد 1015 = محدودیت نرخ (مکث). هیچ کلید یا امضایی در متن خطا نمی‌آید. |
| ۳ | بدون فشار بیشتر | مسدودی تکرار نمی‌شود و بقیهٔ دارایی‌ها (USDC/BTC/ETH) پرسیده نمی‌شوند؛ قبلاً هر همگام‌سازی ۴ دارایی × ۳ تلاش = ۱۲ درخواست ردشده می‌ساخت که خودش می‌تواند مسدودی را سخت‌تر کند. |
| ۴ | راهنمای کیف پول | برای 403/Cloudflare: «ایراد از کلید API نیست؛ VPN/پروکسی را برای کل سیستم روشن کنید یا سرور/کشور دیگری انتخاب کنید». برای کد 1009 متن ویژهٔ مسدودی کشور/منطقه. قبلاً راهنمای کلی «اینترنت را بررسی کنید» نمایش داده می‌شد. |

## اگر پس از این نسخه هنوز 403 بود
متن خط فیوچرز در «گزارش همگام‌سازی» حالا کد Cloudflare را دارد؛ آن را بفرستید:
- **1009** ← IP از کشوری است که Cloudflare/LBank برای این دامنه مسدود کرده؛ VPN سراسری با سرور کشور مجاز.
- **1020 / 1006–1008** ← قانون فایروال یا IP مسدود (معمولاً IP دیتاسنتر یا VPN پرکاربرد)؛ سرور دیگر.
- **1010** ← نباید دیگر رخ دهد؛ اگر رخ داد، بررسی بیشتر لازم است.
- بدون کد Cloudflare ← فهرست IP مجاز کلید API در LBank را بررسی کنید.

## آزمون‌ها
- مجموعهٔ کامل (Qt offscreen): **۲۵۲۳ پاس، ۲ skip، ۰ شکست (۲۵۲۵ آزمون)**.
- تازه (در `tests/test_v251_wallet_watchlist_markets.py`): تشخیص Cloudflare 1020 با Ray ID و بدون نشت کلید؛ 1009 و

## محدودیت‌های صادقانه
- از محیط ساخت به LBank دسترسی نیست؛ کد Cloudflare واقعی شما نامعلوم است و رفع ۱ فقط اگر علت «امضای مرورگر» باشد
  مشکل را کامل حل می‌کند. در بقیهٔ حالت‌ها (کشور/IP) راه‌حل در سمت شبکهٔ شماست و برنامه فقط علت دقیق را نشان می‌دهد.
- برنامه برای دور زدن محدودیت‌های منطقه‌ای کاری انجام نمی‌دهد؛ رعایت قوانین صرافی بر عهدهٔ کاربر است.
