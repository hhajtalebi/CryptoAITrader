# Crypto AI Trader

**برنامه دسکتاپ حرفه‌ای تحلیل بازار ارز دیجیتال و تولید سیگنال فیوچرز**

نسخه ۲٫۲٫۰ · ویندوز ۱۰/۱۱ · پایتون ۳٫۱۱+ (آزموده‌شده تا ۳٫۱۳) · فارسی و انگلیسی

[English README](README_EN.md)

## ⚠ پیش از هر چیز

این برنامه **ابزار تحلیل** است، نه مشاور مالی و نه ربات معامله‌گر.

- پیش‌فرض **کاغذی** است: قیمت زنده است ولی سفارش واقعی نمی‌رود. زیرساخت سفارش واقعی هست، ولی تا وقتی اجراکنندهٔ تأییدشدهٔ صرافی وصل نشده و کاربر خودش حالت زنده را با عبارت تأیید روشن نکرده، هیچ سفارش واقعی ارسال نمی‌شود. جزئیات در [`AI_HANDOVER.md`](AI_HANDOVER.md).
- «درصد اطمینان» یک سیگنال، **احتمال سود نیست**. این عدد فقط می‌گوید چند درصد از عوامل تحلیلی با هم هم‌جهت شده‌اند. اطمینان ۸۰٪ یعنی اندیکاتورها با هم موافق‌اند، نه اینکه ۸۰٪ احتمال دارد معامله سودده شود.
- مسئولیت هر تصمیم معاملاتی کاملاً با خود شماست.

## این برنامه چه می‌کند؟

| قابلیت | توضیح |
|---|---|

| **۱۳ تایم‌فریم** | از ۱ دقیقه تا ۱ هفته؛ تایم‌فریم‌هایی که صرافی ندارد به‌صورت خودکار از تایم‌فریم پایین‌تر ساخته می‌شوند |
| **۲۴ اندیکاتور** | روند، مومنتوم، نوسان، حجم، و حمایت/مقاومت |
| **موتور سیگنال** | خروجی `LONG` / `SHORT` / `WAIT` با ورود، حد ضرر، سه هدف، نسبت ریسک به ریوارد و اهرم پیشنهادی |
| **موتور ریسک** | حد ضرر بر پایه ساختار بازار یا ATR، محدودسازی فاصله حد ضرر، رد کردن ستاپ‌های بی‌کیفیت |

| **هوش پیش‌بینی (جدید در ۲٫۰)** | نردبان ۱۳ افق از ۱ دقیقه تا ۷ روز با توزیع احتمال (P10…P90)، رژیم بازار، سناریوها و دقتِ ثبت‌شده در برابر قیمت واقعی |
| **گزارش‌گیری** | خروجی CSV، Excel، JSON، PDF و HTML |
| **پشتیبان‌گیری** | نسخه پشتیبان دستی و خودکار پیش از هر مهاجرت، با امکان بازیابی |
| **دو زبانه** | فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست، با تعویض زبان بدون بستن برنامه |

### روش ۱ — فایل اجرایی (ساده‌ترین)

فایل `CryptoAITrader.exe` را از پوشه `dist` اجرا کنید. نیازی به نصب پایتون نیست.

### روش ۲ — اجرا از کد

</div>

```bash

cd CryptoAITrader

python -m venv .venv
.venv\Scripts\activate        # ویندوز
source .venv/bin/activate     # لینوکس و مک

python -m pip install --upgrade pip   # مهم: pip قدیمی باعث خطای نصب می‌شود
pip install -r requirements.txt
python main.py
```

## اولین اجرا

با اجرای نخست، یک **ویزارد خوش‌آمدگویی** باز می‌شود و این موارد را می‌پرسد:

۱. زبان و پوسته (تیره، روشن، یا هماهنگ با ویندوز)
۲. صرافی مورد استفاده — پیش‌فرض **LBank** که برای داده عمومی **به هیچ کلید API نیاز ندارد**
۳. تحلیل هوش مصنوعی — به‌صورت پیش‌فرض **خاموش** است؛ برنامه بدون هیچ سرویس پولی کار می‌کند
۴. پارامترهای ریسک — موجودی فرضی حساب، درصد ریسک هر معامله، و بیشینه اهرم

تنظیمات شما در پایگاه داده ذخیره می‌شود و **هرگز با مقادیر پیش‌فرض یا در به‌روزرسانی‌ها بازنویسی نمی‌شود**.

## سیگنال چگونه ساخته می‌شود؟

</div>

```
کندل چند تایم‌فریم  →  ۲۴ اندیکاتور  →  ۳ استراتژی رأی می‌دهند
                                            ↓
                          رأی‌ها با وزن تایم‌فریم جمع می‌شوند
                          (۱ دقیقه: ۰٫۳  …  ۱ هفته: ۲٫۰)
                                            ↓
                        |امتیاز| ≥ ۰٫۲۲  →  LONG یا SHORT
                        در غیر این صورت   →  WAIT
                                            ↓
                    موتور ریسک بررسی می‌کند: فاصله حد ضرر، R/R، اهرم
                    اگر ستاپ قبول نشود  →  WAIT با ذکر دلیل
                                            ↓
              (اختیاری) هوش مصنوعی فقط متن تحلیل را اضافه می‌کند
                     و هیچ‌گاه قیمت‌ها را تغییر نمی‌دهد
```

<div dir="rtl">

**`WAIT` یک خروجی معتبر و مفید است.** بیشتر اوقات بازار ستاپ روشنی ندارد و برنامه عمداً سیگنال نمی‌سازد. برنامه‌ای که همیشه سیگنال می‌دهد، در حال حدس زدن است.

## تحلیل هوش مصنوعی (اختیاری)

برنامه بدون هوش مصنوعی کاملاً کار می‌کند. برای فعال کردن آن سه گزینه دارید:

**۱. مدل محلی (رایگان، پیشنهادی)**

</div>

```bash
# نصب Ollama از ollama.com
ollama pull llama3.1
ollama serve
```

<div dir="rtl">

سپس در تنظیمات: ارائه‌دهنده = `local`، مدل = `llama3.1`

**۲. سرویس سازگار با OpenAI** — نشانی سرویس و کلید API را در تنظیمات وارد کنید.

**۳. ارائه‌دهنده سفارشی** — راهنمای [`docs/ADD_AI_PROVIDER_FA.md`](docs/ADD_AI_PROVIDER_FA.md).

هوش مصنوعی در این برنامه **داده نمی‌سازد**. تنها به داده واقعی بازار از راه ابزارهای تعریف‌شده دسترسی دارد و اگر داده کافی نباشد، موظف است `INSUFFICIENT_DATA` برگرداند. خروجی مدل پیش از نمایش اعتبارسنجی می‌شود.

---

## امنیت کلیدهای API

- کلیدها در **Windows Credential Manager** (از راه `keyring`) ذخیره می‌شوند.
- اگر سرویس سیستمی در دسترس نباشد، در فایلی **رمزنگاری‌شده** خارج از پایگاه داده نگهداری می‌شوند.
- کلیدها **هرگز** در SQLite، در کد، یا در فایل‌های گزارش ذخیره نمی‌شوند؛ یک فیلتر اختصاصی، هر چیزی شبیه کلید را پیش از نوشتن در لاگ ماسک می‌کند.
- نسخه‌های پشتیبان **شامل کلیدها نیستند** (این مورد آزمون خودکار دارد).
